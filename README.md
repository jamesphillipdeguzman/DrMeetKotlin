# DrMeetKotlin

## Overview

-DrMeetKotlin is a simple console-based application built with Kotlin.
It demonstrates basic CRUD operations (Create, Read, Update, Delete) using three related data files:

Patients

Doctors

Appointments

The project uses plain text files instead of a database and performs all operations in memory before saving.

## Technologies I Used:

Kotlin

File I/O

Basic CLI (Command Line Interface)

## Development Environment

IntelliJ IDEA (or any Kotlin IDE)

Local machine

Kotlin

**The language I used is Kotlin.**
